# Registracioni broj

*Pravilnik o bližem sadržaju registracionog broja za privredne i druge subjekte i stečajnu masu i evropskog jedinstvenog identifikatora za privredne subjekte ("Službeni list Crne Gore", br. 116/25 od 14.10.2025)*

## Šta je registracioni broj?

**Registracioni broj** je jedinstveni identifikator koji se dodjeljuje svakom privrednom subjektu, drugom subjektu ili stečajnoj masi pri registraciji u Centralnom registru privrednih subjekata (CRPS). Broj se sastoji iz dva dela: **identifikacione oznake** i **rednog (serijskog) broja**.

## Struktura registracionog broja

```
[Identifikaciona oznaka]-[Redni broj]
```

### Identifikaciona oznaka

Identifikaciona oznaka predstavlja oznaku oblika obavljanja djelatnosti i način dodjeljivanja:

| Oznaka | Tip subjekta |
|--------|--------------|
| 1 | Preduzetnik |
| 2 | Ortačko društvo |
| 3 | Komanditno društvo |
| 4 | Akcionarsko društvo |
| 5 | Društvo sa ograničenom odgovornošću (DOO) |
| 6 | Dio stranog privrednog društva |
| 7 | Nevladina organizacija |
| 8 | Ustanova |
| 9 | Zadruga i kooperativ |
| 10 | Ostali oblici privrednih djelatnosti |
| 11 | Investicioni fond |
| 12 | Stečajna masa |
| 13 | Evropsko ekonomsko interesno udruženje |

### Redni broj

Redni broj je sedam cifara, počev od `0000001` do `9999999`. Označava redosled dodjele u okviru istog tipa subjekta.

## Primjer

```
Registracioni broj: 5-0000123
   5 = društvo sa ograničenom odgovornošću (DOO)
   0000123 = redni broj
```
