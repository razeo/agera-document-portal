# AGERA Document Portal

Flask web aplikacija za generisanje pravnih dokumenata (Odluka o osnivanju & Statut) za DOO u Crnoj Gori. PDF generacija preko WeasyPrint-a, integracija sa AGERA wiki-jem.

## 🚀 Brzi deploy

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/razeo/agera-document-portal)

## Lokalni development

```bash
pip install -r requirements.txt
python -m flask run --port 5000
```
